# Transistir Social Tech

Site institucional estático da Transistir, publicado com GitHub Pages.

## Estrutura

- `index.html`: página inicial, apresentação, princípios de trabalho e cartões de projetos.
- `manifesto.html`: Manifesto a Transistência.
- `projetos/`: estudos de caso públicos.
- `PROPOSTA_ATUALIZACAO_SITE.md`: diagnóstico e diretrizes editoriais da atualização de setembro de 2026.

## Atualização de projetos

Os textos em português e inglês da página inicial ficam no objeto `content` de
`index.html`. Antes de publicar qualquer atualização, confirme:

1. o estágio e o texto público do projeto;
2. se parceiros, marcas, telas e imagens foram autorizados;
3. se o repositório apontado é público, ativo e representativo;
4. que dados territoriais, operacionais, contratuais ou pessoais não estejam expostos.

Os estudos de caso atuais não publicam imagens ou links de repositórios dos
projetos que ainda dependem de validação institucional.
